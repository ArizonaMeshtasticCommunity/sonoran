        Where a node would help

        The struggling nodes are grouped into neighbourhoods, and each neighbourhood is offered places a 1 W node could stand: a node that is already there on a taller mast, or high ground taken from the terrain. This half is predicted, not measured.

        What a siting suggestion cannot know

          Nodes with something we can measure

          Worst first. The order is the number of findings, then a fixed order between them, then how much we know about the node. It is not a score, and no colour here comes from a number. Open a row for the evidence.

          Not enough evidence

          These nodes show no fault we can measure and at least one thing we cannot judge. That is not a clean bill of health. A node that reports almost nothing is usually a node that is switched off.

            Nodes worth a look

            How often each node sends, against the firmware defaults. A node that keeps announcing itself is usually restarting, and a node that keeps restarting usually needs power rather than a change of settings. Counts include packets sent on boot and in reply to a request, so read this as a reason to ask, not as a verdict.
