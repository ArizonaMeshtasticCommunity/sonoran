          Nodes

          How to read this table

          Each signal column asks one question about a node. The answer is one of three:

          • Yes the problem was measured. The number beside it, where there is one, is the measurement.
          • No it was measured and the problem is not there.
          • — cannot tell: there is not enough evidence either way. This is not the same as No.
          Evidence

          Opens the sentence and the counts behind every answer in the row.

          Node and Role

          The node's name, and the role its owner set on it, such as Client or Router.

          Packets

          How many packets from this node reached us in the window. Too few, and most answers are “cannot tell”.

            Nodes worth a look
                
            
              
            
                How often each node sends, against the firmware defaults. A node
                that keeps announcing itself is usually restarting, and a node
                that keeps restarting usually needs power rather than a change
                of settings. Counts include packets sent on boot and in reply to
                a request, so read this as a reason to ask, not as a verdict.
