        Nodes worth a look

        How often each node sends, against the firmware defaults. A node that keeps announcing itself is usually restarting, and a node that keeps restarting usually needs power rather than a change of settings. Counts include packets sent on boot and in reply to a request, so read this as a reason to ask, not as a verdict.
