          Where a node would help

          Places a 1 W node could stand near the nodes that struggle. This half is predicted, not measured.

          What a siting suggestion cannot know

          The struggling nodes are grouped into neighbourhoods, and each neighbourhood is offered places a node could stand: a node that is already there on a taller mast, or high ground taken from the terrain.

            How this is measured

            Nodes are listed worst first: the number of findings, then a fixed order between them, then how much we know about the node. It is not a score, and no colour here comes from a number.

            A node in "not enough evidence" shows no fault we can measure and at least one thing we cannot judge. That is not a clean bill of health. A node that reports almost nothing is usually a node that is switched off.
